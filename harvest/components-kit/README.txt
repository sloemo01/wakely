Wakely components
=================

This folder holds the components you build with an AI coding agent. Each folder in "components" is one component. Wakely loads them while it runs and shows them in Settings > Components, in the Custom group.

To build one, click Make Your Own in Settings > Components and paste the prompt it copies into your agent. Read AGENTS.md for the workflow; sdk/reference.md describes every field, and sdk/component.schema.json is the full schema.

To remove one, right-click its card and choose Remove, or move its folder to the Trash.

Wakely refreshes these documents and the "sdk" folder when the kit version changes. It never changes the folders in "components".
